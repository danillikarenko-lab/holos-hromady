ГОЛОС ГРОМАДИ — сайт-опитування

Файли:
- index.html — структура сайту та форма опитування
- style.css — адаптивний дизайн
- script.js — логіка форми, локальне збереження та демонстраційні результати

Як запустити:
1. Розпакуйте ZIP в одну папку.
2. Відкрийте index.html у сучасному браузері.
3. Інтернет потрібен для завантаження фотографій і шрифту; самі файли сайту локальні.

ВАЖЛИВО:
Це фронтенд-демо. Відповіді зберігаються лише у localStorage конкретного браузера/пристрою й НЕ передаються організаторам. Щоб збирати відповіді від різних людей в одному місці, підключіть бекенд/базу даних або сервіс форм. Перед публікацією додайте реальні контакти організаторів, перевірте текст політики приватності й замініть/перевірте зовнішні зображення.
